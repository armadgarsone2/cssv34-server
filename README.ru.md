## ✨ Возможности

### 🎮 Игровые режимы

| Режим | Описание |
|-------|----------|
| 🌐 **Публичный** | Классика — бесконечные раунды, без урона союзникам |
| 🏆 **Соревновательный** | 30 раундов, стартовые $800, раунд 1:45, C4: 35 сек |
| 💀 **Дедматч** | Респавн 3 секунды, полная броня, мгновенное действие |
| 🔫 **Оружейная** | Прокачка оружия с каждым убийством |
| 🎯 **Снайперский** | Только AWP + нож, быстрый респавн |
| 🔪 **Нож и дым** | Только нож и дымовые гранаты — чистое мастерство |

### 🛠 Кастомные плагины (12)

- **🛒 Простой магазин** — покупка персональных скинов за внутриигровую валюту
- **📊 Система рангов** — общий рейтинг + рейтинг по классам оружия
- **🔇 Гаг/Мьют** — постоянный текстовый и голосовой мьют
- **🛡 Защита спавна** — 3 секунды защиты с обратным отсчётом
- **🚫 Менеджер AFK** — автоматический перенос бездействующих игроков в наблюдатели
- **🎪 Развлекательные режимы** — снайперский и ножевой режимы
- **🔪 Выбор ножа** — индивидуальный выбор ножа (M9 / Бабочка)
- **📢 Приветствие и реклама** — приветственное сообщение, правила, рекламные объявления
- **🏆 Сообщение о победе** — золотое объявление о победе в раунде
- **💀 Респавн дедматча** — быстрый респавн для режима дедматч
- **💬 Журнал чата** — живое ведение журнала чата + уведомления о входе админов
- **📋 Журнал админов** — запись всех действий админов с отметками времени

### 📊 Веб-панель управления

- Живая панель (игроки, карта, статус, активный режим)
- Смена карт и игровых режимов
- Кик / бан игроков (временный или постоянный)
- Управление админами (добавление / удаление)
- Списки банов и гагов с удалением в один клик
- Мониторинг живого чата
- Статистика игроков и таблица лидеров
- Журнал действий админов
- Кнопка перезапуска сервера
- Аутентификация по cookie-сессии

### ⚙️ Инфраструктура

- **Быстрое скачивание** — HTTP-туннель (движок v34 не поддерживает TLS)
- **Античит SMAC** — многоуровневая защита
- **Тикрейт 100** — плавный геймплей
- **Metamod + SourceMod** — фреймворк плагинов
- **Автоматический бэкап** — бэкап данных плагинов каждые 12 часов
- **Ночной рестарт** — автоматический перезапуск в 05:00 с уведомлением игроков

## 🚀 Быстрый старт

```bash
# Клонирование
git clone https://github.com/armadgarsone2/cssv34-server.git
cd cssv34-server

# Установка плагинов
cp plugins/compiled/*.smx /path/to/cstrike/addons/sourcemod/plugins/

# Установка конфигов
cp configs/gamemodes/*.cfg /path/to/cstrike/cfg/gamemodes/
cp configs/sourcemod/* /path/to/cstrike/addons/sourcemod/configs/

# Установка панели
cp panel/panel.py /path/to/cssserver/
cp -r panel/web /path/to/cssserver/

# Перезапуск сервера
systemctl restart css34
```

📖 **Полное руководство:** [docs/INSTALL.md](docs/INSTALL.md)

|---------|----------|

| `!top sniper` | Лучшие снайперы |
| `!top rifle` | Лучшие стрелки |

## 🛠 Команды админов

| Команда | Описание |
|---------|----------|
| `sm_gag <player> [min] [reason]` | Текстовый гаг |
| `sm_mute <player> [min]` | Голосовой мьют |
| `sm_ungag / sm_unmute <player>` | Снять гаг/мьют |
| `sm_gaglist` | Список активных гагов |
| `sm_dm 0/1` | Вкл/выкл респавн дедматча |
